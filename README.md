# محاسبه‌گر اقساط رسا همراه

این پروژه یک اپ اندرویدی (WebView) است که فایل `app/src/main/assets/index.html`
را نمایش می‌دهد. برای ساخت APK نیازی به نصب Android Studio نیست — خود گیت‌هاب
با فایل `.github/workflows/build-apk.yml` به‌صورت خودکار APK را می‌سازد.

## مراحل گرفتن APK از طریق GitHub

۱. یک ریپازیتوری جدید در GitHub بساز (Public یا Private فرقی ندارد).
۲. تمام فایل‌ها و پوشه‌های این پروژه را (با همین ساختار پوشه‌ها) در ریپازیتوری
   آپلود کن:
   - از صفحه ریپازیتوری روی **Add file → Upload files** بزن
   - کل پوشه‌ها را بکش و رها کن (Drag & Drop) — گیت‌هاب ساختار پوشه‌ها را حفظ
     می‌کند
   - Commit کن (دکمه سبز پایین صفحه)
3. به تب **Actions** برو. یک workflow به اسم **Build APK** خودکار شروع به
   اجرا می‌کند (چون پوش به شاخه `main` شده).
4. حدود ۵ تا ۱۰ دقیقه صبر کن تا اجرا تمام شود (علامت ✅ سبز رنگ).
5. روی همان اجرای کامل‌شده کلیک کن، پایین صفحه بخش **Artifacts** را پیدا کن،
   فایل `installment-calculator-apk` را دانلود کن — یک فایل zip است که با باز
   کردنش فایل APK داخلش هست.
6. فایل APK را به گوشی اندرویدت منتقل کن و نصبش کن (باید «نصب از منابع
   ناشناس» را برای همان اپ (فایل منیجر یا مرورگر) فعال کنی).

> اگر workflow اجرا نشد: به تب Actions برو و روی «Build APK» از ستون چپ بزن،
> سپس دکمه **Run workflow** را بزن تا دستی اجرا شود.

## تغییر محتوای اپ

کل محاسبه‌گر در یک فایل HTML است:
`app/src/main/assets/index.html`

هر تغییری در آن فایل بدهی و دوباره Push/Commit کنی، گیت‌هاب خودکار یک APK
جدید می‌سازد.

## تغییر آیکون یا لوگو

- **آیکون اصلی برنامه** (روی صفحه اصلی گوشی): فایل‌های
  `app/src/main/res/mipmap-*/ic_launcher.png` و `ic_launcher_round.png`
- **لوگوی داخل برنامه**: فایل
  `app/src/main/assets/img/logo-inner.png`
